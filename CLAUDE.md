# NaMo Design Studio

Sitio web estático (HTML + CSS + JS, sin build ni dependencias). Ver `LEEME.md` para la estructura de archivos.

- Los textos y proyectos se editan en `js/data.js`, la estructura en `js/app.js`, los estilos en `css/style.css`.
- Si se agrega o cambia una foto en `img/p/`, actualizar su entrada en `js/dims.js`.
- Despliegue: Cloudflare publica automáticamente cada push a `main`. No hay nada más que subir.
- Al terminar un cambio: hacer commit con un mensaje claro y push a `main`.
- No subir capturas de pantalla ni archivos que no pertenezcan al sitio.
